# Controls and Gameplay

## Start and replay

1. Open `shooter.html` in a modern browser.
2. Select **Start Game**.
3. After losing all lives, select **Play Again** to begin a fresh run.

## Keyboard

| Action | Input |
| --- | --- |
| Move up | **W** or **↑** |
| Move down | **S** or **↓** |
| Move left | **A** or **←** |
| Move right | **D** or **→** |
| Shoot | Hold **Space** |

The ship can move diagonally and cannot leave the playfield.

## Touch

On coarse-pointer devices, use the on-screen arrow buttons to move and hold **Fire** to shoot. The touch buttons stay active while pressed.

## Objective

Shoot incoming asteroids to earn **10 points per asteroid**. Avoid colliding with them: each collision costs one life. A run begins with **3 lives** and ends when all are lost. Asteroids become faster and arrive more frequently as your score increases.

Score and lives apply only to the current run; no saved high score is implemented.
