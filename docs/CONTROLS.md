# Controls and Gameplay

## Start and replay

1. Open `shooter.html` in a modern browser.
2. Use the **Upgrades**, **Ship Shop**, and **High Scores** tabs as desired.
3. Select **Launch Mission** on the home screen.
4. After losing all lives, choose **Fly Again** or return to the hangar.

## Keyboard

| Action | Input |
| --- | --- |
| Move up | **W** or **↑** |
| Move down | **S** or **↓** |
| Move left | **A** or **←** |
| Move right | **D** or **→** |
| Shoot | Hold **Space** |

The ship can move diagonally and cannot leave the playfield.

## Touch

On coarse-pointer devices, use the on-screen arrow buttons to move and hold **Fire** to shoot. The touch buttons stay active while pressed.

## Objective

Shoot incoming asteroids to earn **10 points and 1 Star Dust per asteroid**. Avoid colliding with them: each collision costs one life. A run starts with **3 lives**, plus any Hull upgrade bonus, and ends when all lives are lost. Asteroids become faster and arrive more frequently as your score increases.

Spend Star Dust on upgrades and cosmetic ship skins. Hull adds starting lives, Engine increases movement speed, and Blaster increases firing speed. Your personal best and hangar purchases are saved in the current browser; scores are not submitted online.
